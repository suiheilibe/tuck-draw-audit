    期待値と検定の計算方法

    記号

    • aᵢ：効果を使う直前の山札枚数（①で入力）
    • rᵢ：戻す枚数、mᵢ：引く枚数（記録ごとに保存）
    • Nᵢ = aᵢ + rᵢ：戻した後・引く直前の山札枚数
    • kᵢ：戻した後の山札にある対象カードの枚数（②で入力した戻す前の枚数 + rᵢ）
    • Yᵢ：引いた mᵢ 枚のうち対象カードの枚数（③で入力。1枚引きなら 1 か 0）

    モデル（帰無仮説 H₀）

    • 戻した後の山札は一様にシャッフルされる（すべての並びが等確率）
    • 同名カードは区別しない
    • 試行どうしは独立。Nᵢ, kᵢ は与えられた値として扱う（条件付き推測）

    このとき Yᵢ は超幾何分布に従います。

    P(Yᵢ = y) = C(kᵢ, y) · C(Nᵢ−kᵢ, mᵢ−y) / C(Nᵢ, mᵢ)

mᵢ = 1 のとき：P(Yᵢ = 1) = kᵢ / Nᵢ

    期待値と分散

    E[Yᵢ]   = mᵢ · kᵢ / Nᵢ
Var[Yᵢ] = mᵢ · (kᵢ/Nᵢ) · (1 − kᵢ/Nᵢ) · (Nᵢ−mᵢ) / (Nᵢ−1)

S = Σ Yᵢ      μ = Σ E[Yᵢ]      σ² = Σ Var[Yᵢ]

    「引けた枚数 S」は実測、「期待値 μ」は理論上引けるはずの枚数です。S/μ が 1 より大きいほど理論より多く引いています。グラフの帯は累積の μ ± 2σ です。

    検定

    対立仮説は「引く確率が k/N ではない」（両側）です。H₀ のもとでの S の分布を、各試行の分布の畳み込みで正確に計算します。1枚引きだけならポアソン二項分布です。

    f₀(0) = 1,  f₀(x) = 0 (x ≠ 0)
fⱼ(x) = Σ_y fⱼ₋₁(x−y) · P(Yⱼ = y)
P(S = x) = fₙ(x)

    厳密 p 値は、観測値 s と同じかそれより起こりにくい値の確率をすべて足したものです（浮動小数点誤差のため相対許容幅 10⁻⁷ で比較）。

    p = Σ { P(S = x) : P(S = x) ≤ P(S = s) }

Z = (S − μ) / σ   （正規近似。参考値）
    • 離散分布なので、有意水準 5% のとき実際に誤って棄却する確率は 5% 以下になります（保守的）
    • 試行数が少ないうちは S の分布が右に歪むため、Z より厳密 p 値を使ってください
    • 取り消した記録と、k > N や m > N のように成り立たない記録は集計から除きます
    • 設定で「p 値を隠す」がオンのときは、目標試行数に達するまで Z と p 値を表示しません。途中で何度も確認して止めると、誤って棄却する確率が 5% を超えるためです

    実験の設定

    戻す枚数・引く枚数は記録ごとに保存されるので、途中で変えても過去の記録は変わりません。引く枚数が2枚以上のときは超幾何分布で期待値と p 値を計算します。
